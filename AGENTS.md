# Project & Code Guidelines

1. **Language:** Always communicate, document, and write responses strictly in English.
2. **No Emojis & Brand Icons Invariant:** Do not use emojis in UI components, logs, code, or documentation unless explicitly requested by the user. Use clean Lucide SVG icons for interface iconography. Because modern `lucide-react` packages do not export third-party brand logos (e.g. GitHub, Twitter, LinkedIn), never import `Github` from `lucide-react`; use an established inline SVG component (`GithubIcon`) instead.
3. **File Size Limit:** Keep all modular files (frontend components, hooks, backend route handlers, and utilities) under 200 lines of code.
4. **Tone & Profile Alignment:** The user is a marketing professional passionate about technology, automation, technical solutions, and practical data analytics. Keep technical descriptions grounded, honest, practical, and business-focused (avoid exaggerated enterprise titles or buzzwords).
5. **Multi-Language (i18n) Content Synchronization Rule:** Whenever any content, text, project, metric, case study, or UI label is added or updated in the portfolio, you MUST update BOTH English and Spanish versions (`src/data/i18n/siteData.en.json` & `src/data/i18n/siteData.es.json`, `src/data/i18n/ui.en.ts` & `src/data/i18n/ui.es.ts`, and `src/data/i18n/caseStudies.ts`). You MUST run `npm run test:run` to verify that the automated parity test (`src/data/i18n/__tests__/i18nSync.test.ts`) passes with 100% key and structure symmetry before concluding.
6. **Core Brand Credentials & Single Showcase Invariant:** Avoid repeating credential claims across multiple hero/portrait slots. Maintain only the concise verified HUD pill on the executive portrait, while consolidating comprehensive credential lists, issuer logos (Google Data Analytics, Microsoft Power BI, HubSpot Inbound, Python), and verified archive links into the dedicated `#certifications` section.
7. **Color Palette, Glassmorphism & Visual Restraint:** When styling accents, CTAs, and active states, use subdued, architectural slate blues (`#21426E` light / `#4876AB` dark) rather than saturated electric cobalt (`#1E40AF`) or neon colors. The top navigation header must use translucent frosted glassmorphism (`backdrop-blur-xl bg-bg-glass`) rather than opaque solid fills, preserving subtle border definitions without heavy dropshadows.
8. **Architectural Indexing & Monospace Precision:** Major page sections must maintain systematic bracketed index tags (`[01]`, `[02]`, etc.) via `SectionLabel`, and numeric progress or item counters must use high-precision monospace fractional formatting (`01 / 05`).
9. **Navigation Minimalism & Action Pairing:** Keep the top header navigation ultra-clean. Primary contact actions must avoid redundant contact forms, offering strictly two high-intent options: direct instant messaging (**WhatsApp**) and conversational booking (**Schedule Call** dispatched via custom event `open-clippo-schedule` to the Clippo assistant). Secondary site preferences (theme toggling, language switching) are delegated entirely to Clippo.
10. **Hero Centerpiece & Environmental Workspace Portraits:** When workspace/desk setup photography is used in the hero centerpiece, preserve the environment using a wide responsive frame (`aspect-[16/10]` up to `max-w-2xl`) rather than force-cropping to a rigid square. Keep the hero composition editorial and uncluttered by avoiding redundant status eyebrows ("Available for Work", location pills) above the brand anchor.
11. **Kinetic Typography & Scroll-Scrubbed Text Reveals:** When implementing hero or major section title convergence effects (e.g. `ScatterTitle`), use pure Framer Motion with deterministic pseudo-random character seeding (`pseudoRandom(seed)`) to ensure SSR hydration safety. Text reveals must scrub character blur, rotation, and translation into sharp focus over scroll progress without external animation dependencies.
12. **About Me Section & Telemetric Continuity Invariant:** The second major section of the portfolio must be `[01] About me` (`#about`), immediately following the Hero. The hero subtitle must remain concise (displaying only `profile.tagline`), while the in-depth profile narrative and casual Bitcoin enthusiast background (grounded in San Salvador sound money and automated systems) are housed exclusively in `AboutMeSection`. The live Bitcoin & watchdog telemetry bar (`BtcTrendTelemetryBar`) must directly follow `AboutMeSection` to provide immediate tangible proof of the telemetry narrative.
13. **Slogan Architectural Transition & Scroll-Linked Color Morphing Invariant:** The brand slogan "Think Big. Start Small." must be presented as a monumental kinetic transition section (`SloganSection`) positioned between the live telemetry bar and `TrustedStack`. It must implement scroll-driven color interpolation that smoothly floods the background with the established button blue (`#21426E` light / `#1A375E` dark), shifts typography to high-contrast white with ice-blue accents (`#93C5FD`), and incorporates a dynamic diagonal architectural bar (`rotate: -36deg`) anchored in the top-left corner.
14. **Projects Showcase & Accordion Scrollytelling Architectural Invariant:** The featured projects section (`[02] ProjectsSection`, `#projects`) must immediately follow `SloganSection`. It must adopt the full-bleed accordion scroll-reveal architecture inspired by reference implementations:
    - **Unified Full-Bleed Solid Blue Canvas:** The entire section must span full viewport width (100vw) in solid button blue (`#21426E` light / `#162C4E` dark), eliminating any outer margins or floating container silhouettes (`rounded-3xl` card on grey canvas). Section labels must render with the `variant="onDark"` high-contrast white token set.
    - **Full-Bleed Header Bar & Pure White Typography:** Full-bleed header bars with thin borders (`border-t border-b border-white/20 bg-black/15`) featuring bracketed monospace indices (`[01]`, `[02]`) and project titles rendered in crisp, pure white (`style={{ color: "#FFFFFF" }}` / `!text-white font-black uppercase text-xl sm:text-3xl`).
    - **Accordion Scroll Reveal & Rising Title Bar:** As the user scrolls through pinned projects (`transitionProgress`), the active visual collapses its height (`visualHeight: 540px -> 0px`). The incoming project's header bar is positioned directly beneath the active visual, causing it to smoothly rise from the bottom to dock at the top ("va subiendo el nuevo título").
    - **Leftward Image Minimization:** The active media card must minimize towards the left side (`transformOrigin: "left center"`, `scale: 1 -> 0.78`, `x: 0 -> -95px`, `opacity: 1 -> 0`) as the title rises, rather than exiting rightward.
    - **Natural & Soft Media Presentation:** Eliminate artificial dark browser chromes with colored traffic-light dots and URL bars. Showcase screens naturally with soft rounded corners (`rounded-2xl`), deep ambient diffuse shadows (`shadow-[0_25px_60px_-15px_rgba(0,0,0,0.5)]`), clean borders (`border border-white/20`), and a soft peeking card layered behind.
    - **Tailwind CSS v4 Cascade Layer Hygiene:** All global tag selectors (`html, body, h1..h6`) must be wrapped in `@layer base { ... }` in `globals.css` so that utility classes like `.text-white` are never overridden by unlayered tag rules in light mode.
    - **Naming Hygiene & File Limits:** Strictly maintain semantic architectural names (`ProjectsShowcaseStage`, `ShowcaseMediaCard`) and keep every file under 200 LOC.
15. **Hydration Immunity & Browser Extension Resilience:** To prevent SSR/client hydration mismatches, elements susceptible to third-party browser extensions (e.g., accessibility tools like UserWay injecting `data-uw-*`, `uw-v-*`, or `--uw-transform` attributes into `<video>` tags) must guard active dynamic media mounting with an `isMounted` state (`useState(false)` + `useEffect`). During SSR and initial hydration, render a static poster image (`<img>`); mount `<video>` or interactive players only after hydration, paired with `suppressHydrationWarning`. Kinetic text components performing mathematical character scattering or transform calculations (e.g., `ScatterTitle`) must render clean, semantic text during SSR and hydration for SEO and zero-delta DOM matching, activating character-level motion and dynamic transforms only post-hydration via `isMounted`.
